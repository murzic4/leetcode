# 704. Binary Search

**Difficulty:** Easy · **Topic:** Binary Search

**LeetCode:** https://leetcode.com/problems/binary_search/

## Signature

```cpp
int search(vector<int>& nums, int target)
```

## Examples

- nums = [-1,0,3,5,9,12], target = 9 -> 4

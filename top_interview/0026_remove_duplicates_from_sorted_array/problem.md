# 26. Remove Duplicates from Sorted Array

Remove the duplicates in-place from a sorted array and return the new length.

**Difficulty:** Easy · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/remove_duplicates_from_sorted_array/

## Signature

```cpp
int removeDuplicates(vector<int>& nums)
```

## Examples

- nums = [1,1,2] -> 2, nums = [1,2,_]
- nums = [0,0,1,1,1,2,2,3,3,4] -> 5, nums = [0,1,2,3,4,_,_,_,_,_]

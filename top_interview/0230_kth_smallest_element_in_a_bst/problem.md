# 230. Kth Smallest Element in a BST

**Difficulty:** Medium · **Topic:** BST

**LeetCode:** https://leetcode.com/problems/kth_smallest_element_in_a_bst/

## Signature

```cpp
int kthSmallest(TreeNode* root, int k)
```

## Examples

- root = [3,1,4,null,2], k = 1 -> 1

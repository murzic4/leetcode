# 88. Merge Sorted Array

Merge nums2 into nums1 in-place assuming enough space and sorted inputs.

**Difficulty:** Easy · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/merge_sorted_array/

## Signature

```cpp
void merge(vector<int>& nums1, int m, vector<int>& nums2, int n)
```

## Examples

- nums1 = [1,2,3,0,0,0], m = 3, nums2 = [2,5,6], n = 3 -> [1,2,2,3,5,6]
- nums1 = [1], m = 1, nums2 = [], n = 0 -> [1]

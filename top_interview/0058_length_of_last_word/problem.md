# 58. Length of Last Word

Return the length of the last word in the string.

**Difficulty:** Easy · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/length_of_last_word/

## Signature

```cpp
int lengthOfLastWord(string s)
```

## Examples

- s = "Hello World" -> 5
- s = "   fly me   to   the moon  " -> 4

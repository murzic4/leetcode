# 108. Convert Sorted Array to Binary Search Tree

Convert a sorted array into a height-balanced BST.

**Difficulty:** Easy · **Topic:** Divide & Conquer

**LeetCode:** https://leetcode.com/problems/convert_sorted_array_to_binary_search_tree/

## Signature

```cpp
TreeNode* sortedArrayToBST(vector<int>& nums)
```

## Examples

- nums = [-10,-3,0,5,9] -> [0,-3,9,-10,null,5]

# 27. Remove Element

Remove all occurrences of val in-place and return the new length.

**Difficulty:** Easy · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/remove_element/

## Signature

```cpp
int removeElement(vector<int>& nums, int val)
```

## Examples

- nums = [3,2,2,3], val = 3 -> 2
- nums = [0,1,2,2,3,0,4,2], val = 2 -> 5

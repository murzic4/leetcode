# 433. Minimum Genetic Mutation

Return the minimum number of mutations to reach endGene, or -1.

**Difficulty:** Medium · **Topic:** Graph BFS

**LeetCode:** https://leetcode.com/problems/minimum_genetic_mutation/

## Signature

```cpp
int minMutation(string startGene, string endGene, vector<string>& bank)
```

## Examples

- startGene = "AACCGGTT", endGene = "AACCGGTA" -> 1

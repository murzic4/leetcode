# 896. Monotonic Array

Determine if an array is monotonic (non-increasing or non-decreasing).

**Difficulty:** Easy · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/monotonic_array/

## Signature

```cpp
bool isMonotonic(vector<int>& nums)
```

## Examples

- nums = [1,2,2,3] -> true

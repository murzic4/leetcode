# 219. Contains Duplicate II

Determine if there are two equal elements with indices differing by at most k.

**Difficulty:** Easy · **Topic:** Hashmap

**LeetCode:** https://leetcode.com/problems/contains_duplicate_ii/

## Signature

```cpp
bool containsNearbyDuplicate(vector<int>& nums, int k)
```

## Examples

- nums = [1,0,1,1], k = 1 -> true

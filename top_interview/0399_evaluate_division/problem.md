# 399. Evaluate Division

Evaluate division queries from a set of equations with values.

**Difficulty:** Medium · **Topic:** Graph

**LeetCode:** https://leetcode.com/problems/evaluate_division/

## Signature

```cpp
vector<double> calcEquation(vector<vector<string>>& equations, vector<double>& values, vector<vector<string>>& queries)
```

## Examples

- equations = [["a","b"],["b","c"]], values = [2.0,3.0] -> [6.0,0.5,-1.0,1.0,-1.0]

# 424. Longest Repeating Character Replacement

Return the length of the longest substring with the same letter after at most k replacements.

**Difficulty:** Medium · **Topic:** Sliding Window

**LeetCode:** https://leetcode.com/problems/longest_repeating_character_replacement/

## Signature

```cpp
int characterReplacement(string s, int k)
```

## Examples

- s = "ABAB", k = 2 -> 4

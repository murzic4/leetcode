# 238. Product of Array Except Self

Return an array where each element is the product of all others (no division).

**Difficulty:** Medium · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/product_of_array_except_self/

## Signature

```cpp
vector<int> productExceptSelf(vector<int>& nums)
```

## Examples

- nums = [1,2,3,4] -> [24,12,8,6]
- nums = [-1,1,0,-3,3] -> [0,0,9,0,0]

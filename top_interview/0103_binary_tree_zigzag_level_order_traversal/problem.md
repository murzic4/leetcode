# 103. Binary Tree Zigzag Level Order Traversal

Return the zigzag level-order traversal of a binary tree.

**Difficulty:** Medium · **Topic:** Binary Tree BFS

**LeetCode:** https://leetcode.com/problems/binary_tree_zigzag_level_order_traversal/

## Signature

```cpp
vector<vector<int>> zigzagLevelOrder(TreeNode* root)
```

## Examples

- root = [3,9,20,null,null,15,7] -> [[3],[20,9],[15,7]]

# 205. Isomorphic Strings

Determine if two strings are isomorphic.

**Difficulty:** Easy · **Topic:** Hashmap

**LeetCode:** https://leetcode.com/problems/isomorphic_strings/

## Signature

```cpp
bool isIsomorphic(string s, string t)
```

## Examples

- s = "egg", t = "add" -> true
- s = "foo", t = "bar" -> false

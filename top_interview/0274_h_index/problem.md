# 274. H-Index

Compute the h-index from an array of citations.

**Difficulty:** Medium · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/h_index/

## Signature

```cpp
int hIndex(vector<int>& citations)
```

## Examples

- citations = [3,0,6,1,5] -> 3
- citations = [1,3,1] -> 1

# 200. Number of Islands

Count the number of islands in a grid of '1' (land) and '0' (water).

**Difficulty:** Medium · **Topic:** Graph

**LeetCode:** https://leetcode.com/problems/number_of_islands/

## Signature

```cpp
int numIslands(vector<vector<char>>& grid)
```

## Examples

- grid = [["1","1","1","1","0"],...] -> 1

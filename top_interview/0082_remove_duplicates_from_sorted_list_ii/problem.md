# 82. Remove Duplicates from Sorted List II

Remove all nodes that have duplicate numbers, leaving only distinct values.

**Difficulty:** Medium · **Topic:** Linked List

**LeetCode:** https://leetcode.com/problems/remove_duplicates_from_sorted_list_ii/

## Signature

```cpp
ListNode* deleteDuplicates(ListNode* head)
```

## Examples

- head = [1,2,3,3,4,4,5] -> [1,2,5]

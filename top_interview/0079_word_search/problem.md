# 79. Word Search

Determine if a word exists in a grid using adjacent cells.

**Difficulty:** Medium · **Topic:** Backtracking

**LeetCode:** https://leetcode.com/problems/word_search/

## Signature

```cpp
bool exist(vector<vector<char>>& board, string word)
```

## Examples

- board = [["A","B","C","E"],...], word = "ABCCED" -> true

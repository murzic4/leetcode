# 130. Surrounded Regions

**Difficulty:** Medium · **Topic:** Graph

**LeetCode:** https://leetcode.com/problems/surrounded_regions/

## Signature

```cpp
void solve(vector<vector<char>>& board)
```

## Examples

- board = [["X","X","X","X"],["X","O","O","X"],...] -> [["X","X","X","X"],...]

# 114. Flatten Binary Tree to Linked List

Flatten the tree into a right-skewed linked list in-place, following preorder.

**Difficulty:** Medium · **Topic:** Binary Tree

**LeetCode:** https://leetcode.com/problems/flatten_binary_tree_to_linked_list/

## Signature

```cpp
void flatten(TreeNode* root)
```

## Examples

- root = [1,2,5,3,4,null,6] -> [1,null,2,null,3,null,4,null,5,null,6]

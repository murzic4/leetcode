# 452. Minimum Number of Arrows to Burst Balloons

**Difficulty:** Medium · **Topic:** Intervals

**LeetCode:** https://leetcode.com/problems/minimum_number_of_arrows_to_burst_balloons/

## Signature

```cpp
int findMinArrowShots(vector<vector<int>>& points)
```

## Examples

- points = [[10,16],[2,8],[1,6],[7,12]] -> 2

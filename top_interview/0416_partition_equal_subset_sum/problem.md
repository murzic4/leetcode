# 416. Partition Equal Subset Sum

**Difficulty:** Medium · **Topic:** DP

**LeetCode:** https://leetcode.com/problems/partition_equal_subset_sum/

## Signature

```cpp
bool canPartition(vector<int>& nums)
```

## Examples

- nums = [1,5,11,5] -> true

# 212. Word Search II

Find all words from the dictionary present in the board.

**Difficulty:** Hard · **Topic:** Trie

**LeetCode:** https://leetcode.com/problems/word_search_ii/

## Signature

```cpp
vector<string> findWords(vector<vector<char>>& board, vector<string>& words)
```

## Examples

- board = [["o","a","a","n"],...], words = ["oath","pea","eat","rain"] -> ["eat","oath"]

# 637. Average of Levels in Binary Tree

Return the average value of nodes on each level.

**Difficulty:** Easy · **Topic:** Binary Tree BFS

**LeetCode:** https://leetcode.com/problems/average_of_levels_in_binary_tree/

## Signature

```cpp
vector<double> averageOfLevels(TreeNode* root)
```

## Examples

- root = [3,9,20,null,null,15,7] -> [3.00000,14.50000,11.00000]

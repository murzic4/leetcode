# 228. Summary Ranges

Return the smallest sorted list of ranges covering all numbers (e.g. 0..2 -> "0->2").

**Difficulty:** Easy · **Topic:** Intervals

**LeetCode:** https://leetcode.com/problems/summary_ranges/

## Signature

```cpp
vector<string> summaryRanges(vector<int>& nums)
```

## Examples

- nums = [0,1,2,4,5,7] -> ["0->2","4->5","7"]

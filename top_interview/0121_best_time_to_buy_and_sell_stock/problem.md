# 121. Best Time to Buy and Sell Stock

Maximize profit from one buy and one later sell.

**Difficulty:** Easy · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/best_time_to_buy_and_sell_stock/

## Signature

```cpp
int maxProfit(vector<int>& prices)
```

## Examples

- prices = [7,1,5,3,6,4] -> 5
- prices = [7,6,4,3,1] -> 0

# 202. Happy Number

Determine if a number is happy by repeatedly replacing it with the sum of squares of its digits.

**Difficulty:** Easy · **Topic:** Hashmap

**LeetCode:** https://leetcode.com/problems/happy_number/

## Signature

```cpp
bool isHappy(int n)
```

## Examples

- n = 19 -> true
- n = 2 -> false

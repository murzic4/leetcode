# 567. Permutation in String

**Difficulty:** Medium · **Topic:** Sliding Window

**LeetCode:** https://leetcode.com/problems/permutation_in_string/

## Signature

```cpp
bool checkInclusion(string s1, string s2)
```

## Examples

- s1 = "ab", s2 = "eidbaooo" -> true

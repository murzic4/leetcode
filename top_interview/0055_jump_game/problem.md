# 55. Jump Game

Given jump lengths, determine whether you can reach the last index.

**Difficulty:** Medium · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/jump_game/

## Signature

```cpp
bool canJump(vector<int>& nums)
```

## Examples

- nums = [2,3,1,1,4] -> true
- nums = [3,2,1,0,4] -> false

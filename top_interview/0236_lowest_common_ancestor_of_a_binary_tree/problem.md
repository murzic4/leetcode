# 236. Lowest Common Ancestor of a Binary Tree

Find the lowest common ancestor of two given nodes in a binary tree.

**Difficulty:** Medium · **Topic:** Binary Tree

**LeetCode:** https://leetcode.com/problems/lowest_common_ancestor_of_a_binary_tree/

## Signature

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q)
```

## Examples

- root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1 -> 3

# 39. Combination Sum

Find all unique combinations of candidates that sum to target (candidates may be reused).

**Difficulty:** Medium · **Topic:** Backtracking

**LeetCode:** https://leetcode.com/problems/combination_sum/

## Signature

```cpp
vector<vector<int>> combinationSum(vector<int>& candidates, int target)
```

## Examples

- candidates = [2,3,6,7], target = 7 -> [[2,2,3],[7]]

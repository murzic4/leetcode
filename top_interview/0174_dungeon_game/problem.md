# 174. Dungeon Game

Return the knight's minimum initial health to reach the bottom-right room.

**Difficulty:** Hard · **Topic:** DP

**LeetCode:** https://leetcode.com/problems/dungeon_game/

## Signature

```cpp
int calculateMinimumHP(vector<vector<int>>& dungeon)
```

## Examples

- dungeon = [[-2,-3,3],[-5,-10,1],[10,30,-5]] -> 7

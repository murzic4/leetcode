# 80. Remove Duplicates from Sorted Array II

Remove duplicates in-place so each element appears at most twice; return the new length.

**Difficulty:** Medium · **Topic:** Array/String

**LeetCode:** https://leetcode.com/problems/remove_duplicates_from_sorted_array_ii/

## Signature

```cpp
int removeDuplicates(vector<int>& nums)
```

## Examples

- nums = [1,1,1,2,2,3] -> 5, nums = [1,1,2,2,3,_]
- nums = [0,0,1,1,1,1,2,3,3] -> 7, nums = [0,0,1,1,2,3,3,_,_]

# 209. Minimum Size Subarray Sum

Find the minimal length of a contiguous subarray with sum >= target.

**Difficulty:** Medium · **Topic:** Sliding Window

**LeetCode:** https://leetcode.com/problems/minimum_size_subarray_sum/

## Signature

```cpp
int minSubArrayLen(int target, vector<int>& nums)
```

## Examples

- target = 7, nums = [2,3,1,2,4,3] -> 2
- target = 4, nums = [1,4,4] -> 1

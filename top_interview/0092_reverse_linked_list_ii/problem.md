# 92. Reverse Linked List II

Reverse the portion of the list between positions left and right.

**Difficulty:** Medium · **Topic:** Linked List

**LeetCode:** https://leetcode.com/problems/reverse_linked_list_ii/

## Signature

```cpp
ListNode* reverseBetween(ListNode* head, int left, int right)
```

## Examples

- head = [1,2,3,4,5], left = 2, right = 4 -> [1,4,3,2,5]

# 392. Is Subsequence

Determine whether s is a subsequence of t.

**Difficulty:** Easy · **Topic:** Two Pointers

**LeetCode:** https://leetcode.com/problems/is_subsequence/

## Signature

```cpp
bool isSubsequence(string s, string t)
```

## Examples

- s = "abc", t = "ahbgdc" -> true
- s = "axc", t = "ahbgdc" -> false

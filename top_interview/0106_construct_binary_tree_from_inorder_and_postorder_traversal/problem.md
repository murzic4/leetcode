# 106. Construct Binary Tree from Inorder and Postorder Traversal

Build a binary tree from inorder and postorder traversal arrays.

**Difficulty:** Medium · **Topic:** Binary Tree

**LeetCode:** https://leetcode.com/problems/construct_binary_tree_from_inorder_and_postorder_traversal/

## Signature

```cpp
TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder)
```

## Examples

- inorder = [9,3,15,20,7], postorder = [9,15,7,20,3] -> [3,9,20,null,null,15,7]

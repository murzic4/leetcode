# 129. Sum Root to Leaf Numbers

**Difficulty:** Medium · **Topic:** Binary Tree

**LeetCode:** https://leetcode.com/problems/sum_root_to_leaf_numbers/

## Signature

```cpp
int sumNumbers(TreeNode* root)
```

## Examples

- root = [1,2,3] -> 25

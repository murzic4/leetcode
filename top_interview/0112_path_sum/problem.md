# 112. Path Sum

Determine if the tree has a root-to-leaf path summing to targetSum.

**Difficulty:** Easy · **Topic:** Binary Tree

**LeetCode:** https://leetcode.com/problems/path_sum/

## Signature

```cpp
bool hasPathSum(TreeNode* root, int targetSum)
```

## Examples

- root = [5,4,8,11,null,13,4,7,2,null,null,null,1], targetSum = 22 -> true

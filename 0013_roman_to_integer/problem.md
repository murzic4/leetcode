# 13. Roman to Integer

Roman numerals are represented by seven different symbols:

| Symbol | Value |
|--------|-------|
| I      | 1     |
| V      | 5     |
| X      | 10    |
| L      | 50    |
| C      | 100   |
| D      | 500   |
| M      | 1000  |

Given a Roman numeral, convert it to an integer.

## Signature

```cpp
int romanToInt(string s)
```

## Examples

**Example 1:**

- Input: `s = "III"`
- Output: `3`

**Example 2:**

- Input: `s = "LVIII"`
- Output: `58`

**Example 3:**

- Input: `s = "MCMXCIV"`
- Output: `1994`
